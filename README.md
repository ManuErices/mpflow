# 🚀 MPFlow

**Sistema Profesional de Gestión de Proyectos de Construcción**  
*Desarrollado para MPF Ingeniería Civil*

---

## 📋 Descripción

MPFlow es una aplicación web completa para la gestión de proyectos de construcción, diseñada específicamente para optimizar los procesos de MPF Ingeniería Civil. Ofrece una interfaz moderna y profesional para gestionar proyectos, tareas, equipos y cronogramas de manera eficiente.

## ✨ Características Principales

### 🏠 Dashboard Completo
- Estadísticas en tiempo real
- Visualización de métricas clave
- Alertas de tareas vencidas y próximas
- Top colaboradores más productivos

### 📊 Gestión de Proyectos
- Crear, editar y eliminar proyectos
- Asignar colores y estados personalizados
- Seguimiento de progreso en tiempo real
- Estadísticas detalladas por proyecto

### 📋 Gestión de Tareas
- Sistema Kanban con Drag & Drop
- Múltiples vistas (Tablero, Lista, Calendario)
- Prioridades y etiquetas
- Lista de verificación (checklist)
- Asignación a miembros del equipo
- Fechas de vencimiento

### 👥 Gestión de Equipo
- Agregar miembros con roles específicos
- Estadísticas de productividad
- Visualización de carga de trabajo
- Seguimiento de tareas por persona

### 📅 Calendario Interactivo
- Vista mensual de tareas
- Navegación fluida entre meses
- Panel lateral con detalles
- Indicadores visuales de carga

### 🔔 Sistema de Notificaciones
- Notificaciones en tiempo real
- Panel desplegable
- Marcar como leídas
- Historial completo

### 📤 Exportación de Datos
- CSV (tabla de tareas)
- JSON (backup completo)
- TXT (reporte detallado)

### 🔍 Búsqueda y Filtros
- Búsqueda en tiempo real
- Filtros múltiples
- Ordenamiento dinámico

## 🛠️ Tecnologías

- **Frontend**: React 18
- **Build Tool**: Vite
- **Styling**: Tailwind CSS
- **Icons**: Lucide React
- **Persistencia**: LocalStorage

## 📦 Instalación

```bash
# Clonar el repositorio
git clone [url-del-repo]

# Navegar al directorio
cd mpflow

# Instalar dependencias
npm install

# Iniciar servidor de desarrollo
npm run dev

# Compilar para producción
npm run build
```

## 🚀 Uso

1. **Acceder al Dashboard**: Al iniciar, verás las estadísticas generales
2. **Crear Proyecto**: Click en el botón + junto a "PROYECTOS"
3. **Gestionar Tareas**: Navega a la vista de tablero y usa el drag & drop
4. **Agregar Miembros**: Ve a la sección "Equipo" y agrega tu personal
5. **Ver Calendario**: Visualiza todas las tareas por fecha
6. **Exportar Datos**: Usa el botón "Exportar" para descargar reportes

## 📱 Vistas Disponibles

- **Dashboard**: Estadísticas y resumen general
- **Tablero**: Vista Kanban con drag & drop
- **Lista**: Tabla completa con filtros y ordenamiento
- **Equipo**: Gestión de personal y productividad
- **Calendario**: Vista mensual de tareas

## 💾 Persistencia de Datos

Todos los datos se guardan automáticamente en localStorage:
- Proyectos
- Tareas
- Miembros del equipo
- Notificaciones

## 🎨 Personalización

La aplicación utiliza un sistema de colores basado en morado (#9333ea) que representa profesionalismo y modernidad. Todos los componentes siguen un diseño minimalista y consistente.
