# 🚀 MPFlow - Guía de Instalación Rápida

## Para MPF Ingeniería Civil

### 📦 Requisitos Previos
- Node.js 18 o superior
- npm o yarn

### ⚡ Instalación (2 minutos)

```bash
# 1. Extraer el archivo
tar -xzf mpflow.tar.gz
cd mpflow

# 2. Instalar dependencias
npm install

# 3. Iniciar la aplicación
npm run dev
```

### 🌐 Acceso
La aplicación estará disponible en: **http://localhost:5173**

### 🎯 Primeros Pasos

1. **Ver Dashboard**: Al abrir, verás las estadísticas generales
2. **Crear tu primer proyecto**: Click en el + junto a "PROYECTOS"
3. **Agregar una tarea**: Click en "Nueva Tarea" (esquina superior derecha)
4. **Agregar miembros**: Ve a "Equipo" → "Agregar Miembro"

### 💡 Características Principales

✅ Dashboard con estadísticas
✅ Gestión de Proyectos completa
✅ Gestión de Tareas con drag & drop
✅ Vista de Calendario
✅ Gestión de Equipo
✅ Notificaciones en tiempo real
✅ Exportar datos (CSV, JSON, TXT)
